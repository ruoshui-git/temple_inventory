# 导入说明

只有负责人和管理员可以使用导入。入口：更多 → 工作工具。导入分两步，先导入物品，再导入期初库存，两者不能混在一个文件里。

## 物品导入

1. 打开「物品导入」，点「下载模板」。已有物品也可以点「下载物品目录」，改好后再上传。
2. 在「物品导入」工作表填写，不要改列标题。「填写说明」和「示例」工作表只作参考，不会被导入。
3. 上传文件（.xlsx，最多 5 MB、5,000 行）。预览不会写入任何数据。
4. 看预览：新建、更新、无变化、无法导入。更新行可以「查看」前后对比。
5. 点「确认导入」。有无法导入的行时，必须勾选跳过才能继续，也可以下载这些行改好后重新上传。
6. 完成后可以看到生成的物品编号，并下载结果。

### 怎样判断是新物品还是更新

- 填了「物品编号」：更新这个物品。编号不存在时无法导入。
- 没填编号但填了「导入参考号」：参考号已存在时更新，否则新建。
- 两个都没填：系统按名称、类别、单位和说明计算指纹。同一个文件再上传一次不会重复创建。
- 只有名称相同时不算同一物品，预览会提醒。

### 填写规则

| 情况 | 结果 |
|---|---|
| 单元格留空 | 保留原值 |
| 类别或单位不存在 | 无法导入，请先在应用里添加 |
| 条码 | 只增加，不删除；一格可填多个，用“；”分隔 |
| 物品已有库存记录后改库存单位或追踪方式 | 无法导入，规则与物品编辑页相同 |
| 记录效期填“是” | 自动启用批次追踪 |
| 上传后数据被别人改动 | 停止导入，什么都不写入，请重新预览 |

一次导入要么全部成功，要么什么都不写入。

## 期初库存导入

先完成物品导入，再导入期初库存。这里不会创建新物品。

1. 打开「期初库存导入」，点「下载模板」。模板里的「位置清单」列出你有权限的所有实体位置。
2. 需要物品编号时，在物品导入页点「下载物品目录」。
3. 在「期初库存」工作表填写：物品编号、位置、数量为必填；估值单价、批次编号、生产日期、到期日期、序列号按需填写。
4. 在页面上先填「期初日期」和「时间」，不能晚于现在。这就是库存的记录时间。
5. 上传后先看预览，预览不会写入任何数据。结果有三种：新增、无变化（同样的期初已经登记过）、无法导入（会写明原因）。
6. 确认后，系统生成一张期初库存单据，包含这次导入的所有位置，完成后可以直接打开。

### 规则

| 情况 | 结果 |
|---|---|
| 这个物品在这个位置已有任何库存记录或期初库存 | 无法导入，请改用盘点调整 |
| 同一物品、位置、批次在文件里出现两次 | 无法导入 |
| 借出、损坏位置，或没有权限的位置 | 无法导入 |
| 批次管理的物品没填批次编号 | 无法导入；新批次编号会在导入时自动创建 |
| 记录效期的物品没填到期日期 | 无法导入 |
| 序列号物品 | 序列号个数必须等于数量，可用“；”或换行分隔；已在库的序列号无法导入 |
| 估值单价留空 | 优先使用已有估值；没有时按零估值登记（适用于捐赠物资） |
| 再次上传同一个文件 | 已登记的行显示为无变化，不会重复登记 |

导入提交时，这些位置的其他操作会稍等片刻。大批量导入请在空闲时进行。
