# 物资管理 · 功能总览与验收清单

本文件是给非技术同事看的中文版功能说明和验收清单，内容与 [acceptance-matrices.md](acceptance-matrices.md) 对应。运行 `scripts/dx /workspace/development/frappe-bench/env/bin/python scripts/build-feature-overview` 可生成同名 Excel 文件（docs/feature-overview.zh-CN.xlsx）。

图例：✅ 已验证可用 · ⚠️ 可用，但有说明 · ❌ 暂无 · — 不适用

验证日期：2026-10-30，在开发环境用示例数据，于电脑（1440×900）和手机（390×844）上逐项核对。

## 功能总览

| 模块 | 能做什么 | 在哪里 |
|---|---|---|
| 首页 | 一眼看到库存总量、按仓库或类别的库存分布、即将到期和已过期批次、未归还借用、最近流动记录；可直接发起入库、出库、借出、调拨 | 首页 |
| 库存列表 | 查看每个物品的可用、借出、损坏数量和所在位置；按类别、位置、库存状态筛选；可切换表格或卡片 | 库存 → 库存列表 |
| 效期批次 | 按批次查看到期日期和剩余天数，区分已过期、未过期、无效期 | 库存 → 效期批次 |
| 仓库与库位 | 按 区域 → 房间 → 货架 管理存放位置：新建、改名、移动、停用、细分、删除；查看某个位置里的所有物品 | 库存 → 仓库 |
| 损坏待处理 | 集中查看损坏物品，选择修复归库或报废 | 库存 → 损坏待处理 |
| 入库 / 出库 / 调拨 | 登记物品进入、离开或在位置之间移动；可按批次和到期日期登记；提交前有核对页 | 首页快速操作、货物流动 |
| 借用与归还 | 登记借出（借用方、活动），从借出单直接登记归还、损坏或遗失；随时查看谁借了什么、还有多少未归还 | 借用 |
| 盘点 | 对授权范围内的位置逐一清点；空白表示未清点，0 表示清点为零；数量一致的不产生记录；提交后自动调整库存 | 更多 → 盘点调整 |
| 损坏、遗失、修复、报废 | 记录物品损坏或遗失，修复后归库，或正式报废 | 更多 |
| 物品资料 | 新建和修改物品：名称、类别、单位、条码、照片（可裁剪）、附件；可停用或删除未被使用的物品 | 物品详情 |
| 类别与单位 | 管理物品类别；单位使用中文名称（个、件、箱…），可设置是否只允许整数 | 更多 → 类别 / 单位 |
| 活动 | 把借用和流动记录关联到法会等活动，按活动查看相关记录 | 更多 → 活动 |
| 草稿与自动保存 | 填写中的单据自动保存为草稿，换一台设备也能继续；未填完的内容暂存在本浏览器 | 更多 → 草稿 |
| 附件 | 给物品和单据添加照片、PDF 等文件，在应用内直接查看；已提交的单据也可补充附件 | 物品详情、单据详情 |
| 报表与导出 | 每个列表页就是一份报表：筛选、分组、选择显示列后导出 Excel 或 CSV，可附带物品图片和附件（ZIP） | 每个列表页的“导出” |
| 批量操作 | 在库存、效期批次、损坏待处理、借用页点“选择”后勾选多行，一次入库、出库、调拨、报损、修复、报废或登记归还 | 列表页右上角“选择”（手机在“…”菜单中） |
| 历史库存 | 按时间段查看期初、入、出、调整、期末数量 | 更多 → 报表 |
| 扫码 | 用手机摄像头、扫码枪或手动输入条码，快速找到物品或加入单据 | 搜索栏、单据编辑 |
| 通知 | 新流动、撤销修改、盘点、导出完成等事件的应用内通知和手机推送；可选每日效期提醒 | 更多 → 通知设置 |
| 显示设置 | 每个账户可设置默认日期范围、文字大小、显示密度、表格显示哪些列 | 更多 → 设置 |
| 手机与电脑 | 手机和电脑都能查看；可安装到手机主屏幕像普通应用一样打开；导出和录入建议在电脑上进行 | 更多 → 安装到手机 / 电脑 |
| 权限与安全 | 每个账户只能看到和操作被授权的仓库；所有权限由服务器检查 | — |
| 与 ERPNext 一致 | 所有库存数量都记在 ERPNext 中；在 ERPNext 后台修改的单据在本应用中同样可见、可编辑 | — |
| 系统更新提示 | 系统更新期间显示中文“系统正在更新”页面，并自动刷新 | 全部页面 |

## 导出规则

以下规则适用于所有列表页的导出。

| 要求 | 结果 | 说明 |
|---|---|---|
| 导出列与页面显示的列一致，顺序相同 | ✅ | |
| 导出全部符合条件的行，而不只是已加载的行 | ✅ | 例如页面显示 30 行，导出 2,651 行 |
| 中文表头和显示名称 | ✅ | 不出现 ERPNext 内部名称 |
| 按单位的合计行 | ✅ | |
| “导出说明”页：页面、筛选、分组、排序、期间、时间、账户、行数 | ✅ | 仅 Excel |
| 易读的文件名：页面–期间–时间 | ✅ | 例如“货物流动 · 明细-2026-10-01至2026-10-29-20261029-0019.xlsx” |
| 分组导出：灰色分组行、小计、可折叠 | ✅ | CSV 不分组 |
| 附带文件：物品图片或图片和附件，打包为 ZIP | ✅ | |
| 导出进度与下载提示 | ✅ | 显示“读取数据 / 写入文件 / 打包附件”进度条 |

## 数据录入

已提交的库存单据遵循 ERPNext 规则：草稿可以修改或删除；已提交的单据先“取消”（库存自动冲回），再“修订”生成一份可修改的新草稿。

| 对象 | 添加 | 查看详情 | 修改 | 删除 | 停用 / 取消 | 说明 |
|---|---|---|---|---|---|---|
| 物品 | ✅ | ✅ | ✅ | ✅ | ✅ 停用 | 未被任何记录使用时才能删除；库存为零时才能停用 |
| 单位 | ✅ | ✅ | ✅ | ✅ | ✅ 停用 | 可改显示名称、单位类别和是否只允许整数；仍有物品使用时不能停用 |
| 物品类别 | ✅ | ✅ | ✅ | ✅ | — | 未被使用时才能删除 |
| 库房 | ✅ | ✅ | ✅ | ✅ | ✅ 停用 | 没有库存、记录、权限和下级位置时才能删除 |
| 物品照片 | ✅ | ✅ | ✅ | ✅ | — | 可裁剪、替换、移除 |
| 条码 | ✅ | ✅ | ✅ | ✅ | — | 扫码和搜索都能找到物品 |
| 物品附件 | ✅ | ✅ | — | ✅ | — | |
| 单据附件 | ✅ | ✅ | — | ✅ | — | 已提交的单据也可增删附件；图片、PDF、文本可在应用内查看 |
| 入库记录 | ✅ | ✅ | ✅ 草稿 | ✅ 草稿 | ✅ 取消 / 修订 | |
| 出库记录 | ✅ | ✅ | ✅ 草稿 | ✅ 草稿 | ✅ 取消 / 修订 | 过期物品通过出库移出 |
| 调拨记录 | ✅ | ✅ | ✅ 草稿 | ✅ 草稿 | ✅ 取消 / 修订 | |
| 借出记录 | ✅ | ✅ | ✅ 草稿 | ✅ 草稿 | ✅ 取消 / 修订 | |
| 归还记录 | ✅ | ✅ | ✅ 草稿 | ✅ 草稿 | ✅ 取消 / 修订 | 从未归还的借出单开始登记，也可在库存、借用页“选择”后批量登记；一张归还单可包含不同借用方和活动的借出 |
| 库房盘点记录 | ✅ | ✅ | ✅ 草稿 | ✅ 草稿 | ✅ 取消 / 修订 | 数量一致时不产生记录 |
| 活动 | ✅ | ✅ | ✅ | ✅ | ✅ 归档 | 未被引用时才能删除 |
| 批次 | 通过入库 | ✅ | ✅ | — | — | 可修正到期日期、生产日期 |
| 草稿 | 自动保存 | ✅ | ✅ | ✅ | — | 更多 → 草稿 列出所有草稿和本浏览器暂存 |
